# Building unisolver

## Toolchains (once)

- Rust stable (`rust-toolchain.toml` pins the channel and components).
- Flutter 3.47 on `PATH` (installed directly or through a version manager such as fvm).
- Android: JDK 21 (JDK 26 breaks AGP's JdkImageTransform) and NDK 27.

```bash
# Typical macOS locations (Homebrew JDK, Android Studio SDK); adjust to your installation
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_NDK_HOME=$HOME/Library/Android/sdk/ndk/27.0.12077973
flutter config --jdk-dir "$JAVA_HOME"    # once
```

Rust cross targets (`rustup target add`, eight in total): `aarch64-apple-ios aarch64-apple-ios-sim
aarch64-linux-android x86_64-linux-android aarch64-apple-darwin x86_64-apple-darwin
x86_64-pc-windows-msvc aarch64-pc-windows-msvc`.

## Tests and checks

```bash
cargo test --workspace --release --features "imageio satellites"
cargo clippy -p unisolver-core -p unisolver-synth -p unisolver-cabi -p namesgen -p solvecli -p xtask \
  --all-targets --features "imageio satellites" -- -D warnings
python3 scripts/ci/check_public_text.py      # English-only public text
bash scripts/ci/check_windows.sh             # Windows cross-check from macOS
cargo xtask upstream check                   # third_party/tetra3 = pinned upstream + patch queue
(cd packages/unisolver_flutter && flutter test)
(cd packages/unisolver_flutter/example && flutter test test/ && flutter test integration_test/solve_e2e_test.dart -d macos)
```

Enable the repository's git hooks once per clone: `git config core.hooksPath .githooks`
(one-line commit messages; fmt and clippy before pushing `main`).

## Development

`flutter run` is enough: cargokit compiles `unisolver_frb` inside each platform build.

After changing `packages/unisolver_flutter/rust/src/api/**`, regenerate the bindings (in
`packages/unisolver_flutter/`):

```bash
flutter_rust_bridge_codegen generate && dart run build_runner build
```

The C header `crates/unisolver-cabi/include/unisolver.h` is regenerated by
`cargo build -p unisolver-cabi`.

## Release builds (in `packages/unisolver_flutter/example/`)

| Platform | Command | Notes |
|---|---|---|
| macOS | `flutter build macos --release` | universal binary via Xcode ARCHS |
| Android | `flutter build appbundle --release --target-platform android-arm64,android-x64` | gradle abiFilters and target-platform agree (debug builds add armv7; release follows this command) |
| iOS | `flutter build ipa` | needs signing; CI can use `flutter build ios --no-codesign` |
| Windows | `flutter build windows --release` | **needs a Windows host** (dart-sys compiles C with MSVC); on macOS `scripts/ci/check_windows.sh` checks unisolver-core for both targets |

## Troubleshooting

- `Unable to locate a Java Runtime` → set JAVA_HOME as above and run `flutter config --jdk-dir`.
- cargokit cannot find the NDK → set `ANDROID_NDK_HOME`.
- Generated Dart misses `*.freezed.dart` → run `dart run build_runner build` again.
- Do not edit `rust/` while a build runs in the background (cargokit may read a half-written state).
